# Analyse mondiale de la sécurité alimentaire 🌾

## 🎯 Objectif du projet
Ce projet s'inscrit dans le cadre de mon cursus de formation Data Analyst. L'objectif est de réaliser une analyse approfondie des indicateurs de sécurité alimentaire à l'échelle mondiale, afin d'identifier les zones de vulnérabilité et de comprendre les tendances structurelles qui impactent la disponibilité et l'accès à la nourriture.

L'analyse repose sur le traitement de données complexes pour transformer des informations brutes en insights exploitables et visuels.

## 🚀 Résultat
L'aboutissement de ce projet est une présentation interactive (via Slidev) qui synthétise les conclusions majeures de l'étude. Le travail comprend :
*   Un pipeline de nettoyage et de transformation des données.
*   Une analyse exploratoire permettant de mettre en lumière les corrélations critiques.
*   Une restitution visuelle structurée pour une communication claire des résultats.
